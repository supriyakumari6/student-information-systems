# student-information-systems
A web-based **Student Information System** built as a DBMS project. It lets an institution store, view and manage student records in one place, replacing scattered paper files and spreadsheets with an organized database.

## Features

- **Secure login:** only authorized users can access the system
- **Dashboard:** a quick overview of the system after login
- **Student records:** add, view, update and delete student details
- **Student profile:** a dedicated page showing one student's complete information
- **Organized storage** of student data, including:
  - Enrollment number
  - Name
  - Class and branch
  - Phone number and contact details
  - Email address
  - Other personal information
